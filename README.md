# Homebrew Tap for Tidywise

Install [Tidywise](https://github.com/floorianmb/tidywise) on macOS (Apple silicon, macOS 14+):

```bash
brew install --cask floorianmb/tap/tidywise
```

To avoid the one-time Gatekeeper prompt (the app is not signed with a paid Apple Developer certificate yet):

```bash
brew install --cask --no-quarantine floorianmb/tap/tidywise
```

Upgrade later:

```bash
brew upgrade --cask tidywise
```
